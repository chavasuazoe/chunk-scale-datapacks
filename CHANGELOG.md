## [0.1.0] - 2026-07-21

### Added

- Cambio automático de escala al cruzar límites de chunks.
- Cinco escalas: 1.00×, 0.40×, 0.75×, 1.50× y 3.00×.
- Selección automática del chunk de origen.
- Comando para cambiar el origen.
- Comando para restablecer temporalmente las escalas.
- Compatibilidad declarada con Minecraft Java 26.3 Snapshot 4, datapack format 111.0.
